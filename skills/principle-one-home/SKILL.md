# One home

A rule, a mapping, or a list lives in one file. Everyone else links
to it.

If you are about to paste a table that already exists, stop and
reference the owner. Drift between copies is the failure mode.

When two names describe the same thing, keep one and rename the
callers. Do not keep a compatibility alias without a deletion date.
