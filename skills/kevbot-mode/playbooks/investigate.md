# Investigate

Read-only. The deliverable is a cited answer, not a patch.

## Steps

1. Restate the question in one sentence and what evidence would settle
   it.
2. Run the **how** skill on the subsystem the question names. Stay
   read-only.
3. If the question is historical (why this shape, why this number),
   search git history and any issue tracker or docs the session can
   reach. Label inference as inference.
4. Answer the question with paths, symbols, and commands from this
   session. List remaining unknowns.
5. Do not edit files. If a fix is obvious, say so in one paragraph and
   stop.
